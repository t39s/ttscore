# ttScore Team — журнал изменений

Документ содержит историю реализованных версий `ttscore_team`, начиная с `v0.1`.

## v0.3.1 — 2026-08-27

Статус: **реализована локально, не опубликована, ещё не принята**.

Исправленная patch-версия создана на основе точной `v0.3.0` по результатам её формального ревью. Продуктовые возможности и `schemaVersion: 3` не расширялись.

### Исправлено

- **R-01:** `winsToFinish`, `order`, `gamesA` и `gamesB` принимаются только как целые JSON-числа; строки, boolean и `null` больше не преобразуются через `Number(...)`.
- **R-02:** `updatedAt` проверяется как реальная календарная дата и допустимое время; исключены 31 февраля, часы `24`, минуты или секунды `60`, а также смещения за пределами `±14:00`.
- **R-03:** начальная дата в режиме создания определяется по локальному календарному дню пользователя, а не по UTC.
- **R-04:** при подготовке предварительного просмотра и перед скачиванием выполняется проверка существования опубликованного `<id>.json`; совпадение вызывает предупреждение о замене. Ошибка или четырёхсекундный тайм-аут не блокируют скачивание, поэтому финальный GitHub diff остаётся обязательным контролем.

### Сохранено без изменения

- Форматы 2×2, 3×3 и 4×4, циклическое расписание и личные встречи до трёх побед в партиях.
- Режимы `create`, `view` и `edit` и открытая JSON-модель `schemaVersion: 3`.
- Ручная загрузка JSON через GitHub без API, токена и авторизации в приложении.
- Отделение общего исходного кода от файлов конкретных встреч.

### Проверено

- Автоматические тесты: **67 из 67 пройдены**.
- Добавлены регрессии для строгих числовых типов, невозможных даты, времени и часового пояса, локального календарного дня и классификации результата проверки ID.
- Проверены синтаксис JavaScript, JSON примера, структура HTML, контрольные суммы и HTTP-выдача файлов.

### Границы версии

- Проверка ID носит предупредительный характер и не резервирует имя файла; GitHub diff обязателен.
- Браузерный E2E не выполнен из-за ограничения среды; перед принятием требуется ручная проверка.
- Публикация не выполнялась.
- Отдельный ZIP changelog не создаётся; обновлённый журнал входит только в основной пакет.

## v0.3.0 — 2026-08-27

Статус: **прошла формальное ревью, не принята; замечания исправлены в `v0.3.1`**.

Первая версия создания командной встречи с нуля на основе неизменённой `v0.2.2`.

### Добавлено

- Режим `ttscore_team_0.3.0.html?mode=create` без параметра `match`.
- Форматы командной встречи 2×2, 3×3 и 4×4.
- Форма идентификатора, даты, места, названий команд, составов и необязательной первой live-ссылки.
- Автоматические ID спортсменов `a1…aN` и `b1…bN`.
- Генерация всех `N²` уникальных пар в циклическом порядке.
- Первая личная встреча автоматически получает `current`, остальные — `planned`.
- Предварительный просмотр и сохранение точного `<id>.json`.
- Поддержка командных ничьих 2:2 и 8:8.
- Отдельный чистый модуль `creator.mjs`.

### Изменено

- Модель переведена на `schemaVersion: 3`.
- Размер команд обобщён с фиксированных трёх до равных составов из 2–4 спортсменов.
- Число личных встреч проверяется как `N²`.
- `winsToFinish` вычисляется и проверяется как `floor(N² / 2) + 1`: 3, 5 или 9.
- Режим просмотра показывает формат и итоговую ничью.
- Режим редактирования завершает встречу без назначения следующей как после победы, так и после ничьей.
- Демонстрационный JSON «Север — Юг» переведён на `schemaVersion: 3` без изменения состава и расписания.

### Сохранено

- Личная встреча проводится до трёх побед в партиях.
- Результаты `3:0`, `3:1`, `3:2` и зеркальные.
- Ручная публикация JSON через GitHub без токена и API.
- Защита редактора от устаревшего источника.
- Открытая модель данных без шифрования.
- Отделение исходного кода от конкретных встреч.

### Проверено

- Автоматические тесты: **62 из 62 пройдены**.
- Проверены генерация 2×2, 3×3 и 4×4, циклический порядок и полное покрытие пар.
- Проверены пороги 3, 5 и 9, досрочная победа и ничьи 2:2 и 8:8.
- Проверены режимы `create`, `view` и `edit`, имя файла, DOM-контракт и отсутствие GitHub API.
- Проверены строгий JSON-контракт, безопасность ссылок, синтаксис и HTTP-выдача.

### Границы версии

- `schemaVersion: 2` не принимается страницей `v0.3.0`; старые JSON продолжают использовать `v0.2.2`.
- Ручная перестановка расписания и импорт существующего JSON не реализованы.
- Браузерный E2E не выполнен; перед принятием требуется ручная проверка.
- Публикация не выполнялась.
- Отдельный ZIP changelog не создаётся; журнал входит только в основной пакет.

## v0.2.2 — 2026-08-27

Статус: **принята пользователем, не опубликована**.

Исправленная patch-версия создана на основе неизменённой `v0.2.1` по результатам формального ревью.

### Исправлено

- **R-01:** перед подготовкой и перед скачиванием повторно загружается опубликованный JSON; изменившийся источник блокирует операцию.
- Для сравнения используется устойчивая ревизия данных, не зависящая от порядка ключей объектов.
- **R-02:** ручное «Обновить» очищает форму; при смене текущей встречи показываются прежний и новый ID.
- **R-03:** начальные и конечные пробелы в строках строгого JSON-контракта отклоняются; имя файла строится из проверенного канонического ID.
- **R-04:** ссылки с обратными косыми чертами, percent-encoded сегментами `..` и некорректным percent-encoding отклоняются.
- **R-05:** `updatedAt` требует ISO 8601 с явно указанным часовым поясом.
- Object URL скачиваемого JSON отзывается отложенно; временный элемент ссылки добавляется в DOM и удаляется после запуска скачивания.

### Сохранено без изменения

- `schemaVersion: 2` и формат командного JSON.
- Спортивная модель, завершение после пятой победы и статусы личных встреч.
- Ручная загрузка JSON через GitHub без токена, API или авторизации в приложении.
- Отделение общего исходного кода от данных конкретных встреч.
- Имя `matches-source.mjs`.

### Проверено

- Автоматические тесты: **43 из 43 пройдены**.
- Добавлены регрессии для всех R-01—R-05.
- Проверены неизменяемость исходного объекта, обычный переход и пятая победа без назначения следующей встречи.
- Проверены синтаксис JavaScript и JSON, структура HTML и HTTP-выдача файлов.

### Границы версии

- Проверка свежести не резервирует файл между скачиванием и ручным GitHub commit; финальный diff остаётся обязательным контролем.
- Браузерный E2E не выполнен из-за ограничения среды; перед принятием требуется ручная браузерная проверка.
- Публикация не выполнялась.
- `ttScore_0.3.5.html` не изменялся.
- Отдельный отчёт изменений не создавался; изменения зафиксированы в этом журнале.

## v0.2.1 — 2026-08-27

Статус: **реализована локально, не опубликована, ещё не принята**.

### Добавлено

- В `ttscore_team_0.2.1.html` добавлен отдельный режим `?match=<id>&mode=edit` для подготовки обновлённого JSON.
- Редактор автоматически загружает опубликованный JSON; начальный выбор локального файла не требуется.
- Форма принимает итог завершённой личной встречи, обязательный `reportUrl` и необязательный `liveUrl` следующей встречи.
- Одна проверяемая операция завершает текущую встречу, пересчитывает командный счёт и при необходимости запускает следующую.
- После пятой победы следующая встреча не назначается, а оставшиеся позиции отображаются как `Не требовалась`.
- Перед сохранением показываются итоговый командный счёт, следующая встреча или факт завершения, а также полный JSON.
- Файл сохраняется под точным именем `<id>.json` для последующей ручной загрузки в GitHub.

### Изменено

- `meeting-source.mjs` переименован в `matches-source.mjs` во всём коде, тестах и документации.
- Общие файлы перенесены в `assets/0.2.1/`; общий HTML переименован в `ttscore_team_0.2.1.html`.
- В режиме редактирования отключено автоматическое перечитывание JSON каждые 30 секунд, чтобы введённые данные не исчезали.
- Изменение формы аннулирует прежний предварительный результат и требует повторной проверки.
- `schemaVersion: 2` и все продуктовые правила `v0.2.0` сохранены без изменения.

### Безопасность и границы

- Редактор работает локально в браузере и не содержит GitHub-токена, API-клиента или авторизации.
- Публичный режим не содержит ссылки или кнопки перехода в режим редактирования.
- Загружаемый JSON повторно проходит строгую проверку до и после перехода состояния.
- Публикация остаётся ручной: сохранённый файл загружается в `team/team-matches/` через GitHub.
- Если браузер добавил к имени `(1)`, файл нужно вернуть к точному имени `<id>.json` до загрузки.

### Проверено

- Автоматические тесты: **35 из 35 пройдены**.
- Проверены обычный переход, зеркальный результат, сохранение live-ссылки завершённой встречи и необязательная live-ссылка следующей.
- Проверена пятая победа без назначения шестой встречи.
- Проверены отсутствие текущей встречи, повторное обновление завершённой встречи, опасные URL и некорректный `updatedAt`.
- Проверены режимы `view` и `edit`, защита параметра `match`, полное переименование файла и отсутствие данных примера в общем коде.

### Границы версии

## v0.1.1 — 2026-08-27

Статус: **принята**.

Редакция исправляет замечания формального ревью `v0.1`. Исходная версия `v0.1` не изменялась.

### Исправлено

- После пятой личной победы командная встреча завершается; шестой и последующие результаты отклоняются.
- Проверяется строгая последовательность исходных состояний: `finished* → current? → planned*`.
- После пятой победы незавершённые позиции отображаются как `Не требовалась`.
- Неизвестные и ошибочно названные поля JSON отклоняются.
- Для завершённой личной встречи обязательны корректный результат и непустой `reportUrl`.
- Календарная дата проверяется как реальная дата, а не только как строка формата `YYYY-MM-DD`.
- После неудачного автообновления страница сохраняет последние успешно загруженные данные и явно помечает их как устаревшие.
- Уточнено описание полной публичности данных и сохранения прежних редакций в истории Git.

### Принятое уточнение

- `reportUrl` — универсальная ссылка на опубликованный отчёт `ttScore`, а не ссылка только на JSON.
- Ссылка может вести на автономный HTML-отчёт, защищённый отчёт `.ttscore` или открытый JSON.
- Формат, размещение и публикация отчёта находятся вне ответственности `ttscore_team`.

### Проверено

- Автоматические тесты модели: **11 из 11 пройдены**.
- Синтаксис JSON и JavaScript проверен.
- Структура HTML проверена.
- Зависимости от Firebase, `ttscore-live` и `/liveReportsV2` отсутствуют.

### Границы версии

- Браузерный E2E не выполнялся.
- Публикация на GitHub Pages или Firebase Hosting не выполнялась.
- `ttScore_0.3.5.html` не изменялся.

## v0.1 — 2026-08-26

Статус: **заменена версией v0.1.1**.

### Добавлено

- Первый статический прототип публичного оглавления одной командной встречи с постоянным адресом.
