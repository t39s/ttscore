# ttScore Team — журнал изменений

Документ содержит историю реализованных версий `ttscore_team`, начиная с `v0.1`.

## v0.2.0 — 2026-08-27

Статус: **реализована локально, не опубликована, ещё не принята**.

### Изменено

- Общий исходный код отделён от данных конкретных командных встреч.
- Для всех встреч используется единый HTML-файл `ttscore_team_0.2.0.html`.
- Общие JavaScript- и CSS-файлы размещены в `assets/0.2.0/`.
- Каждая командная встреча хранится отдельным JSON-файлом в `team-matches/`.
- Конкретная встреча выбирается параметром `?match=<id>`.
- Идентификатор проверяется до построения пути; переходы к произвольным файлам исключены.
- Модель данных переведена на `schemaVersion: 2`.
- Массив личных встреч переименован из `matches` в `individualMatches`.
- Названия команд, спортсмены, дата, порядок пар, результаты и ссылки удалены из общего кода.
- Жёстко заданная надпись о вымышленных данных удалена из общей страницы; вымышленность относится только к примеру JSON.
- `reportUrl` сохранён универсальной ссылкой на автономный HTML, защищённый отчёт `.ttscore` или открытый JSON.
- Новая командная встреча создаётся добавлением одного JSON-файла без копирования HTML, JavaScript или CSS.

### Структура

```text
team/
  ttscore_team_0.2.0.html
  assets/0.2.0/
    app.mjs
    meeting-source.mjs
    model.mjs
    styles.css
  team-matches/
    <id>.json
```

Адрес конкретной встречи:

```text
https://t39s.github.io/ttscore/team/ttscore_team_0.2.0.html?match=<id>
```

### Проверено

- Автоматические тесты: **23 из 23 пройдены**.
- Проверены спортивная модель, строгий JSON-контракт и завершение после пятой победы.
- Проверены обязательность `match`, отклонение повторяющегося параметра и защита от обхода пути.
- Проверено принятие HTML-, защищённых и JSON-ссылок в `reportUrl`.
- Проверено отсутствие данных демонстрационной встречи в общем HTML, JavaScript и CSS.
- Синтаксис JavaScript, JSON и структура HTML проверены.

### Границы версии

- Браузерный E2E не выполнен: среда не разрешила облачному браузеру открыть локальный HTTP-сервер.
- Публикация на GitHub Pages или Firebase Hosting не выполнялась.
- `ttScore_0.3.5.html` не изменялся.
- Отдельный отчёт изменений не создавался; изменения зафиксированы в этом журнале.

## v0.1.1 — 2026-08-27

Статус: **принята**.

Редакция исправляет замечания формального ревью `v0.1`. Исходная версия `v0.1` не изменялась.

### Исправлено

- После пятой личной победы командная встреча завершается; шестой и последующие результаты отклоняются.
- Проверяется строгая последовательность исходных состояний: `finished* → current? → planned*`.
- После пятой победы незавершённые позиции отображаются как `Не требовалась`.
- Неизвестные и ошибочно названные поля JSON отклоняются.
- Для завершённой личной встречи обязательны корректный результат и непустой `reportUrl`.
- Календарная дата проверяется как реальная дата, а не только как строка формата `YYYY-MM-DD`.
- После неудачного автообновления страница сохраняет последние успешно загруженные данные и явно помечает их как устаревшие.
- Уточнено описание полной публичности данных и сохранения прежних редакций в истории Git.

### Принятое уточнение

- `reportUrl` — универсальная ссылка на опубликованный отчёт `ttScore`, а не ссылка только на JSON.
- Ссылка может вести на автономный HTML-отчёт, защищённый отчёт `.ttscore` или открытый JSON.
- Формат, размещение и публикация отчёта находятся вне ответственности `ttscore_team`.

### Проверено

- Автоматические тесты модели: **11 из 11 пройдены**.
- Синтаксис JSON и JavaScript проверен.
- Структура HTML проверена.
- Зависимости от Firebase, `ttscore-live` и `/liveReportsV2` отсутствуют.

### Границы версии

- Браузерный E2E не выполнялся.
- Публикация на GitHub Pages или Firebase Hosting не выполнялась.
- `ttScore_0.3.5.html` не изменялся.

## v0.1 — 2026-08-26

Статус: **заменена версией v0.1.1**.

### Добавлено

- Первый статический прототип публичного оглавления одной командной встречи с постоянным адресом.
- Открытый `match.json` с названиями команд, тремя спортсменами в каждой команде и девятью уникальными межкомандными парами.
- Ручной порядок личных встреч и состояния `planned`, `current`, `finished`.
- Автоматический расчёт командного счёта из результатов завершённых личных встреч.
- Завершение командной встречи после пятой личной победы и отображение оставшихся позиций как `Не требовалась`.
- Live-ссылка для текущей личной встречи и `reportUrl` для завершённой.
- Автоматическое перечитывание `match.json` каждые 30 секунд и ручная кнопка обновления.
- Работа без авторизации, шифрования, Firebase и изменений `ttScore 0.3.5`.
- Демонстрационная встреча с вымышленными данными.

### Выявлено ревью

- Допускался шестой завершённый матч после уже достигнутой пятой победы.
- Не обеспечивалась строгая последовательность состояний.
- Неизвестные поля JSON не отклонялись.
- Ссылка на отчёт не была обязательной для `finished`.
- Проверка календарной даты была недостаточной.
- Не было явной индикации устаревших данных после ошибки автообновления.
- Описание публичности данных и Git-истории требовало уточнения.

Все перечисленные замечания исправлены в `v0.1.1`.
