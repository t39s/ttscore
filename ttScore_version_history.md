## Инвариант версии

Для каждой новой версии должны совпадать четыре представления:

1. имя HTML-файла: `ttScore_<версия>.html`;
2. версия, отображаемая внутри приложения;
3. версия в ключе `localStorage`;
4. версия в этой таблице.

Расхождение любого из этих представлений считается дефектом выпуска.

> Новая схема имён HTML-файлов и версионных ключей применяется перспективно, начиная с версии `0.1.9.23b`. Исторические файлы не переименовываются и не изменяются.


## Правило выпуска следующей версии

Перед передачей новой HTML-версии проверить:

- [ ] имя файла соответствует `ttScore_<версия>.html`;
- [ ] версия внутри приложения совпадает с именем файла;
- [ ] ключ `localStorage` содержит ту же версию;
- [ ] в таблице добавлена строка с той же версией;
- [ ] явно указано одно изменение версии;
- [ ] явно указано, что не изменялось;
- [ ] зафиксированы выполненные проверки и их ограничения;
- [ ] принято решение: `ACCEPTED`, `REJECTED`, `DIAGNOSTIC` или `PENDING`.
