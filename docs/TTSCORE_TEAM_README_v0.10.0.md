# ttScore Team v0.10.0 RC1

Paired with `ttScore 0.5.0`.

New capability: Team-mode completed personal matches receive an automatic report link backed by immutable canonical JSON stored in the existing `ttscore-list` Realtime Database.

Deployment requires the bundled `firebase-database-rules.json` and the complete versioned `team/assets/0.10.0/` directory.

Accepted baseline remains `ttscore_team 0.9.0` / RC9 until owner production acceptance.
